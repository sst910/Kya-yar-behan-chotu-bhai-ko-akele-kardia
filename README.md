# The People vs. My Cousin ❤️

A playful interactive GitHub Pages website built as a 3-part cousin-bond story:

1. The good old days — gossip, fun, sharing and memories.
2. The Fiancé Update™ — funny evidence, diagnostics and a mock courtroom.
3. The emotional ending — missing the old bond without villainizing the fiancé.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/root`, then save.
6. GitHub will provide the Pages URL.

Everything is self-contained: no frameworks, external libraries, images, APIs, or build step.
